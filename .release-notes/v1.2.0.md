## Flux v1.2.0 — Performance & Habits Update

Flux v1.2.0 is the latest stable release, focused on smoother performance, better habit tracking, and a cleaner interface.

### ✦ New
- **Habits page:** a dedicated habit manager backed by new SQLite tables.
- **Calendar:** rewritten calendar page with a custom month grid.
- **Calendar utility:** the original `ui/mini_calendar.py` is restored in the source package.

### ⚡ Performance & motion
- Background animation timers now run at approximately **16 ms per frame (~60 FPS)** instead of 33 ms.
- Animation movement is time-based, so the speed remains consistent when frame timing changes.
- Animations pause while the app window is hidden or minimized.
- Theme lookup and shared UI code received cleanup passes.

### ◈ Interface
- Main UI font changed from Segoe UI to **Helvetica**.
- Light and Sakura themes keep Segoe UI.
- Theme catalog and shared styling have been consolidated into dedicated modules.

### ✓ Verification
- A 374-step headless test run passed.
- Coverage included all 14 themes plus Custom, all 8 pages, habit create/toggle/delete, Calendar, animation pause/resume hooks, all animations, and 311 painted widgets.
- The GitHub Actions Windows build completed successfully, including the application smoke test, executable verification, portable package, and installer.

### 📦 Downloads
- **FluxSetup.exe** — Windows installer.
- **Flux-portable-windows.zip** — portable build.

### Data
- Personal development data is not included in the public source or release package. Flux creates its local database for the user.
