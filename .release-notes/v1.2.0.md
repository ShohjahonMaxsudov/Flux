## Flux v1.2.0 — Performance & Habits Update (Developer BETA)

A focused update built around smoother performance, better habit tracking, and a cleaner recovered source tree.

### ✦ New
- **Habits page:** a dedicated habit manager backed by new SQLite tables.
- **Calendar:** rewritten calendar page with a custom month grid.
- **Calendar utility:** the original `ui/mini_calendar.py` is restored in the source package.

### ⚡ Performance & motion
- Background animation timers now run at approximately **16 ms per frame (~60 FPS)** instead of 33 ms.
- Animation movement is time-based, so the speed remains consistent when frame timing changes.
- Animations pause while the app window is hidden or minimized.
- Theme lookup and shared UI code received cleanup passes.

### ◈ Interface
- Main UI font changed from Segoe UI to **Helvetica**.
- Light and Sakura themes keep Segoe UI, matching the previous release.
- Updated source layout keeps the theme catalog and shared styling in consolidated modules.

### ✓ Verification
- A 374-step headless test run passed.
- Coverage included all 14 themes plus Custom, all 8 pages, habit create/toggle/delete, Calendar, animation pause/resume hooks, all animations, and 311 painted widgets.
- The automated run does not replace a real visual check on a Windows desktop. Please inspect Habits, Calendar, and several themes after installing.

### 📦 Windows builds
- **FluxSetup.exe** — Windows installer.
- **Flux-portable-windows.zip** — portable build.

### Developer notes
- The personal `flux.db` was deliberately excluded. Flux creates a fresh local database on first launch.
- This is a source-first Developer BETA; no prebuilt executable was included in the source upload. The Windows builds linked above were generated by GitHub Actions.
- Some recovered files may not retain original comments or every attribute type hint because parts of the source were reconstructed from compiled Python 3.13 bytecode.
